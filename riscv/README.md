# ⚡ RISC-V Assembly Labs

A collection of low-level programs and architectural experiments written in RISC-V Assembly. 

---

## 🏗️ The Workbench
All code in this repository is designed to run on the **RARS** (RISC-V Assembler and Runtime Simulator).

| Lab Section | Focus |
| :--- | :--- |
| **Logic & Math** | Register operations, arithmetic, and logical bit-shifting. |
| **Memory & Stack** | Manipulating the stack pointer and heap allocation. |
| **Control Flow** | Branches, jumps, and recursive function calls. |

---

## 🚦 How to Run
1. Open the **RARS** simulator.
2. Load the `.asm` file from this directory.
3. Assemble (Press `F3`) and Run (Press `F5`).

> **Note:** Ensure your RARS settings are set to the default RISC-V integer instruction set.
